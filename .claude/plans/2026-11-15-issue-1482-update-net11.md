# Issue #1482 — Update to net11

https://github.com/DevBetterCom/DevBetterWeb/issues/1482

Issue body: "And update all packages". No comments, labels, or linked items.

## Assumptions

- Target `net11.0` for every project; SDK 11.0.100 is installed locally.
- "Update all packages" = bump every `PackageVersion` in `Directory.Packages.props` to its latest
  stable release, **except** packages pinned with an explicit reason in the file
  (`Stripe.net` webhook API version). That one stays pinned.
- Prereleases are not adopted.
- Aspire is not on `main` (it exists only on the old `ShadyNagy/outboxserver` branch). Adding it is
  tracked separately in #1484 (requested by the user during this work).

### Not addressed (with reasons)

- **Transitive `Microsoft.AspNetCore.WebUtilities` 9.0.4 advisory** via `NimblePros.Vimeo` →
  `NimblePros.ApiClient 2.1.2`: already on main; Web resolves the framework copy at runtime. Better
  fixed by bumping NimblePros.Vimeo upstream than by turning on transitive pinning here.
- **Swagger functional test**: Swagger is only mapped in Development; functional tests run in
  `Testing`, so a test would need app-startup changes beyond this issue.
- **Strict `AssertConfigurationIsValid`**: profiles have many existing unmapped members (unrelated to
  the upgrade); fixing them is a separate cleanup.
- **Identity UI Bootstrap 4 obsolete warning**: a build warning, not an error; moving to Bootstrap 5 is a
  UI change for another issue.
