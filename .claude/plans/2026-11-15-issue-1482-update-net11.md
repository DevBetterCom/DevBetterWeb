## Assumptions

- Target `net11.0` for every project; SDK 11.0.100 is installed locally.
- "Update all packages" = bump every `PackageVersion` in `Directory.Packages.props` to its latest
  stable release, **except** packages pinned with an explicit reason in the file
  (`SixLabors.ImageSharp` license, `Stripe.net` webhook API version). Those stay pinned.
- Prereleases are not adopted unless the package is already on a prerelease
  (`Serilog.Sinks.ApplicationInsights`).
- A major-version bump that needs non-trivial code migration may be held back; any such
  holdback is recorded below with the reason.
